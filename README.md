# Lab 2 – Data Applications with Streamlit

In this lab, I built a data application using Streamlit, going from exploring basic widgets to deploying a multi-page competitor analysis app powered by live Google Play Store data and a HuggingFace sentiment analysis model.

## Streamlit Exploration

I started by creating a test_app.py file to explore and test all of Streamlit's core capabilities, such as dislay widgets, input widgets, filter widgets, button widgets, dat widgets, Streamlit Magic, and UX design. 

### Theming
I created a .streamlit/config.toml file to customize the app's theme, setting the primary color, background, text color, and font. This file sits next to test_app.py and is automatically picked up by Streamlit on startup.
